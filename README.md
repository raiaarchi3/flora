# Flora

Next.js (App Router) + Tailwind CSS, all components in `.jsx`.

    npm install
    npm run dev      # http://localhost:3000

- Add flowers in `data/flowers.js`.
- Photos and videos: edit `data/media.js` (instructions are inside), or just name files after the flower id in `public/flowers/`, e.g. `rose.png`, `rose.mp4`.
